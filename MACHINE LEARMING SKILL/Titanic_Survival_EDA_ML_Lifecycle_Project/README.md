# Titanic Survival — EDA and ML Lifecycle Mapping Project

## Files
- `Titanic_Survival_EDA_ML_Lifecycle.ipynb` — complete Jupyter Notebook
- `code/titanic_eda_lifecycle.py` — complete runnable Python script
- `dataset/titanic_train.csv` — 891-row Titanic training dataset
- `outputs/*.csv` — generated CSV analysis outputs
- `outputs/figures/*.png` — generated EDA figures
- `requirements.txt` — required Python packages
- `run_project.bat` — Windows one-click runner
- `project_metadata.json` — project metadata

## Kaggle reference
Official Kaggle competition:
https://www.kaggle.com/competitions/titanic

Kaggle documents the Titanic training set as 891 labeled records and the test set as 418 records. The target is `Survived`.

Direct Kaggle download was not available in this execution environment because Kaggle competition data may require account/rules access. The included CSV is the standard 891-row Titanic training dataset available locally in the runtime and uses the standard Kaggle column structure.

## Run
From the project root:

```text
python code/titanic_eda_lifecycle.py
```

Or double-click:

```text
run_project.bat
```

Then open:

```text
Titanic_Survival_EDA_ML_Lifecycle.ipynb
```

## Project scope
This is **Project 1: Titanic Survival — EDA and ML Lifecycle Mapping**.
