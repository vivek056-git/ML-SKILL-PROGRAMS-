# Titanic Survival — Preprocessing Pipeline and Cleaned Dataset

## Project 2

### Steps
1. Load Titanic data
2. Inspect missing values
3. Engineer FamilySize
4. Engineer IsAlone
5. Engineer FarePerPerson
6. Extract/group passenger Title
7. Split train/test
8. Median-impute numeric variables
9. Most-frequent-impute categorical variables
10. One-hot encode categorical variables
11. Standardize numeric variables
12. Fit preprocessing only on training data
13. Transform test data
14. Export cleaned and processed CSV files
