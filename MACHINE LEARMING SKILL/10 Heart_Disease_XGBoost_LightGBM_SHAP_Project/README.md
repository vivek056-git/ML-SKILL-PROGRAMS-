# Project 10 — Heart Disease: XGBoost, LightGBM & SHAP

Educational 920-row practice dataset using the same Heart Disease-style schema as Projects 8 and 9.
Not a clinical dataset.

Models:
- XGBoost
- LightGBM
- SHAP explainability
- permutation importance

Outputs include model comparison, predictions, confusion matrices, ROC curves, cross-validation,
SHAP feature importance and figures.

Run: `python code/heart_disease_xgboost_lightgbm_shap.py`
