# Project 3 — Adult Income: Feature Engineering and EDA

The official Adult Census Income dataset is available on Kaggle and is based on 1994 Census data.
This package includes a **5,000-row practice dataset with the same 15-column schema** because the
current execution environment could not directly download the large external CSV.

For a submission requiring the official data, download `adult.csv` from Kaggle and replace
`dataset/adult_income.csv`.

Official Kaggle dataset:
https://www.kaggle.com/datasets/uciml/adult-census-income

Official Kaggle Census Income competition:
https://www.kaggle.com/c/census-income
